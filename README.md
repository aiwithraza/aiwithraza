## 👋 About

I'm a Cloud Data Engineering student who learns by building and documenting. I wrote my own open data engineering book, **[Data Foundry](https://data-engineering-book.vercel.app/)**, covering the full path from SQL and Python to orchestration, cloud warehousing, streaming, and the two big clouds (AWS and Azure).

| Area | What I work with |
|---|---|
| **Foundations** | Data engineer's mindset, modern data stack, tooling setup |
| **SQL** | Querying fundamentals, shaping and analyzing data, advanced techniques |
| **Python** | Core language, working with data, OOP |
| **Orchestration** | Apache Airflow: scheduling, architecture, running Airflow with Docker |
| **Engineering practices** | Docker, CI/CD with GitHub Actions, Bash scripting |
| **Agentic data engineering** | AI-assisted workflows, Claude Code and Cursor, agentic pipelines |
| **Cloud warehousing** | Snowflake, dbt |
| **Real-time data** | Streaming vs batch, Kafka, Change Data Capture |
| **AWS** | Core services, services by category, advanced AWS |
| **Azure** | Medallion architecture with ADF and Databricks, Fabric, Synapse Analytics |
